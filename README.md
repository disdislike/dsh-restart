# dsh-restart

一键重启 DeepSeek Harness 桌面端。装好插件后会出现一个「重启 DSH」按钮，点一下就能让应用完整重启，刚安装或改动的插件立刻生效。

按钮位置可以在 **设置 → 通用 → 重启按钮位置** 里切换，选好后立即搬过去，并自动对齐到那个位置既有的排版（尺寸、间距、颜色都跟随所在那一行）。

## 可选位置

| 位置 | 实际座位 | 说明 |
|---|---|---|
| 工作区顶部左（标题前）（默认） | `conversation.header.leading` | 会话标题左侧，始终显示 |
| 工作区顶部中（标题旁） | `conversation.session.header.actions` | 会话标题右侧，跟标题栏一起显示 |
| 工作区顶部右（工具栏） | `conversation.session.header.utilities` | 图标按钮，和右侧工具区同排 |
| 输入框左侧 | `conversation.input.left` | 输入框工具行的左端 |
| 侧边栏底部 | `sidebar.footer.action` | 头像与设置那一行上方；该位置空闲时才可用 |

「工作区顶部中/右」和「输入框左侧」都在会话里才显示（没有打开会话时不出现）；前两类位置在设置行里会标注这一点。

## 使用

1. 安装并启用本插件（`dsh-restart`）。
2. 需要换位置就去 **设置 → 通用**，在「重启按钮位置」里选一处；不需要就保持默认。
3. 点击「重启 DSH」，按钮变成「正在重启…」，约 1 秒后应用窗口关闭，几秒内自动重新打开。

选择保存在当前浏览器（localStorage），所以桌面窗口和浏览器标签页各自记住自己的选择。

## 实现

- **Host 半边**（`index.js`）注册两个路由：
  - `GET /dsh-restart/status`：当前进程是否运行在桌面端（Electron）里；`dsh web` 命令行版里没有可重启的应用外壳，按钮会自动隐藏。
  - `POST /dsh-restart/restart`：校验自定义请求头后，启动一个分离的重启助手进程。
- **重启助手**（`restart-helper.cjs`）先等待 1.2 秒，让界面显示「正在重启…」，随后结束 Electron 主进程；等主进程和 Host 进程都退出、文件句柄释放后，再用同一个可执行文件重新启动应用。新进程不会带 `ELECTRON_RUN_AS_NODE`，也不会和旧实例的单实例锁冲突。
- **浏览器半边**（`client.js`）用 `ctx.slots.inject(座位, ...)` 注册按钮：位置偏好存在 localStorage，切换时先释放旧座位再挂到新座位；侧边栏底部被别的插件占用时该选项置灰，按钮回落到默认位置并在设置行里说明。所有形态都只用自己的 CSS 类适配所在行的尺寸与间距，不使用绝对定位，文案走客户端 locale 服务。

## 已知限制

- **系统托盘菜单无法由插件扩展。** 托盘菜单由 Electron 主进程（`app.asar` 内的 `lib/main.js`）硬编码，只有「打开」「退出」两项，插件系统没有对应的扩展点。要在托盘里加「重启」，只能修改已安装应用的 `main.js`，并且每次应用更新后都会被覆盖。
- **左上角「应用」菜单同样由 Electron 主进程构建**，插件无法添加菜单项。仓库里的 `tools\patch-application-menu.cmd` 可以给已安装的应用打等长补丁，在「应用」菜单里加「重启」（带备份与 `--restore`；应用更新后需要重打）。
- **头像弹出的菜单（设置 / 意见反馈 / 退出登录）无法由插件追加菜单项。** 它是 `@deepseek-ai/dsh-client-ui-settings-account` 的私有组件，没有插槽；替换它需要整体重写头像、登录状态与退出登录确认。
- **侧边栏底部那一行默认被官方「动态插件」面板占满**（该面板固定占满整行宽度），所以该位置默认置灰；停用那个面板后即可选用，按钮会自动搬过去。
- 重启会直接结束进程，不会像「退出」那样先询问是否有正在运行的任务。
- 只有在桌面端（Electron）里才出现这个按钮，`dsh web` 命令行版会自动隐藏。用普通浏览器打开桌面端同一个地址时按钮也会显示，但点击前会先确认：重启后那个页面会断开，需要从系统托盘重新打开应用。

## 卸载

在设置 → 插件中停用或删除 `dsh-restart` 即可，不会残留后台进程或配置。
